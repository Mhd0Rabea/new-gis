# المرحلة 006: لوحة المعلومات وإدارة البيانات

## قصص المستخدم
1. P1 — لوحة المعلومات: مؤشرات الطبقات والمعالم وآخر التحديثات.
2. P1 — إدارة البيانات: البحث والتصفية والفرز والترقيم وفتح المعلم على الخريطة.
3. P2 — التحليلات الوصفية: توزيعات ومقارنات دون تنبؤ أو AI.
4. P2 — التقارير: معاينة وطباعة وتنزيل CSV بالعربية.

## المتطلبات
- FR-001 تحويل الرئيسية إلى لوحة معلومات.
- FR-002 دعم الطبقات التسع وإخفاء حقول النظام.
- FR-003 البحث والتصفية والفرز والانتقال المباشر للخريطة.
- FR-004 توحيد التعريب والأرقام والتاريخ بنظام 12 ساعة.
- FR-005 حالات تحميل وخطأ وفراغ وإعادة محاولة.
- FR-006 دعم RTL ولوحة المفاتيح وعرض 360px.
- FR-007 تحليلات وصفية فقط.
- FR-008 تقارير مطبوعة وCSV دون الحقول الداخلية.
- FR-009 إعادة استخدام API الحالية بلا خدمة جديدة.

## المؤجل
المعالجة وDEM وسحابات النقاط و3D للمرحلة 007، وAI للمرحلة 008.

## النجاح
ظهور المؤشرات خلال ثانيتين، فتح المعلم خلال نقرتين، عمل الطبقات التسع، وعدم وجود تمرير أفقي عند 360px.
