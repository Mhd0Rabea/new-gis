# Research

- **PostGIS بدل مزامنة الملفات**: جميع العملاء على الجداول نفسها لمنع تضارب النسخ.
- **الأدوار**: `mgos_editor` للتحرير، `mgos_geoserver` للقراءة، وحساب API مستقل؛ لا ملكية schema.
- **سجل الاختبار**: سجل حقيقي يختاره المستخدم وحقل وصفي قابل للاسترجاع، بلا معلم بديل.
- **GeoServer cache**: WFS/API دليل مباشر؛ WMS دليل بصري مساعد وقد يحتاج cache bypass.
