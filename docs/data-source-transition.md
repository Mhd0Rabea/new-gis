# انتقال مصادر البيانات إلى الرفع المحلي

تاريخ القرار: 2026-10-08

## القرار

أُزيلت بيانات البداية التدريبية وملفات العينات ومخرجات المعالجة المرتبطة بها. أصبح التطبيق لا يولد بيانات بديلة ولا يختار ملفًا افتراضيًا.

## ما تغير

- فُرّغت طبقات وجداول MGOS التشغيلية، مع بقاء البنية والمخطط فقط.
- حُذفت ملفات Raster وLAS/LAZ وعينات التصنيف والموديل التدريبي.
- تتطلب صفحة المعالجة رفع ملف Raster أو LAS/LAZ قبل تشغيل أي عملية.
- يتطلب تصنيف النقاط رفع ملف إعداد نموذج JSON وملف نقاط من المستخدم.
- تبقى الوثائق والأدلة التاريخية للمرحلات السابقة كما هي لتسجيل ما حدث؛ لا تمثل مصدر بيانات تشغيل حالي.

## مسؤولية المستخدم

يرفع المستخدم بياناته محليًا ويتحقق من قانونية استخدامها ودقتها ونظام الإحداثيات. لا يرسل التطبيق هذه الملفات إلى خدمة خارجية ضمن المسار الحالي.
