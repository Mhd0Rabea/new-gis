# خريطة طريق MGOS

## الهدف

مشروع تعليمي يوضح المسار الكامل من ArcGIS Pro إلى تطبيق ويب مكاني. تعتمد المراحل الحالية على بيانات يرفعها المستخدم محليًا؛ لا توجد عينات افتراضية. تصنيف سحابات النقاط بالذكاء الاصطناعي مفعّل ضمن المرحلة 008 بعد اكتمال وظائف المشروع الأساسية والتحقق من جودة البيانات والاختبارات. يبقى النطاق تعليميًا وببيانات مرفوعة من المستخدم، مع مراجعة بشرية إلزامية قبل اعتماد أي نتيجة.

## خط التنفيذ

```text
001 ArcGIS Foundation
  → 002 PostGIS Integration
  → 003 GeoServer Publishing
  → 004 NestJS Spatial API
  → 005 React Map Integration
  → 006 Dashboard & Data Management
  → 007 Advanced Spatial Processing
  → 008 AI Point Classification (مفعّلة)
  → 009 Operational Coverage (مكتملة)
  → 010 Decision Intelligence (مكتملة وظيفيًا)
  → 011 Staged Spatial Import & Shared Source (مكتملة وظيفيًا)
  → 012 Operational Sync Verification (مكتملة ومغلقة)
```

## العقود الثابتة

- التخزين والتحرير الداخلي: `EPSG:32637`.
- GeoJSON الصادر والوارد عبر API: `EPSG:4326`.
- أسماء Feature Datasets وFeature Classes والجداول لا تُترجم ولا تُختصر.
- GeoServer مسؤول عن العرض والقراءة المكانية؛ NestJS مسؤول عن الكتابة والمعالجة.
- File Geodatabase مصدر تعلم ArcGIS مستقل، وPostGIS مخزن التكامل والنشر.
- PostGIS هو مصدر الحقيقة التشغيلي المشترك؛ يتصل به ArcGIS Pro وMGOS وGeoServer مباشرة حسب الصلاحيات.
- المسارات والمنافذ وبيانات الاتصال إعدادات بيئية قابلة للتغيير.

## المرحلة 007

أُغلقت وظيفيًا بتاريخ 2026-10-07 بعد نجاح طابور المعالجة والاسترداد، عمليات GDAL وPDAL، رفع الملفات وتنزيل المخرجات، معاينة GeoJSON على الخريطة، وربط DEM والطبقات التشغيلية بمشهد Cesium. الأدلة في `docs/evidence/007-advanced-spatial-processing/`.

## المرحلة 009

أُغلقت ضمن نطاق التغطية التشغيلية بتاريخ 2026-10-08: تُعرّف الخريطة الطبقات التسع بألوانها وتسمياتها، وتعرض إدارة البيانات الجداول الوصفية مع روابط العلاقات المكانية. أضيفت خارطة قدرات AI إلى مركز المعالجة لتفصل بين تصنيف سحابات النقاط المتاح فعليًا والقدرات المخططة. صفحة الإدارة تبقى رقابية للقراءة فقط؛ لا يشمل هذا النطاق إنشاء المستخدمين أو تعديل الصلاحيات. لم يُنفذ اختبار تفاعلي للطبقات التسع بطلب صريح من المستخدم. الأدلة في `docs/evidence/009-operational-coverage/`.

## الذكاء الاصطناعي

المرحلة `008-ai-point-classification` **مفعّلة وليست مؤجلة**. توفر تصنيفًا تعليميًا لسحابات النقاط المرفوعة، وعرض الثقة، والمراجعة البشرية، والمقارنة بخط أساس معلن. لا يُقبل اعتماد أو نشر أي نتيجة تلقائيًا، وتبقى إعادة التدريب والبيانات الحقيقية خارج نطاق الإصدار الحالي.

## تجهيز بيئة جديدة

الدليل الموحد هو `docs/setup-and-portability.md`. قبل تنفيذ أي مرحلة على جهاز جديد شغّل `scripts/preflight.ps1` مع Target المرحلة، ولا تثبت مكوّنًا قبل مراجعة النتيجة.

## المرحلة 010

اكتملت القدرات الوظيفية بتاريخ 2026-10-10. يوفّر مركز القرار تقييم المخاطر، وترتيب جاهزية المسارات، وإنذارات التتبع المكانية، والتوقع المقيد بنطاق وفترة، واستخراج مناطق التغير من GeoTIFF. تُحفظ النتائج وقرارات المراجعة وملاحظاتها في PostgreSQL/PostGIS، ولا تُعتمد تلقائيًا. في 2026-10-13 أُدخلت بيانات مدنية مفتوحة وحقيقية من ريف دمشق: أربعة طرق عامة، ومحجر مدني، ونقاط تتبع عامة، ومؤشرات جوية، وصورتا Sentinel-2؛ ونُفذت عليها تحليلات Quickstart ونجح WFS وWMS. بقيت المراجعة البشرية للإنذار والتوقع ومرشح التغير فقط، دون إنشاء عينات بديلة. الأدلة في `docs/evidence/010-decision-intelligence/`.

## المرحلة 011

اكتملت وظيفيًا بتاريخ 2026-10-11. أضيف مسار استيراد مرحلي يفصل الرفع والفحص والمراجعة عن الاعتماد التشغيلي، ويكشف التكرارات ويطلب قرارًا صريحًا قبل تنفيذ معاملة ذرية. اعتمدت PostGIS كمصدر الحقيقة الوحيد المشترك بين ArcGIS Pro وMGOS وGeoServer، مع `row_version` لمنع الكتابة فوق تعديل أحدث. تحقق المسار بملف المستخدم الحقيقي ذي 12 معلمًا دون إنشاء عينات. الأدلة في `docs/evidence/011-staged-spatial-import/`.

## المرحلة 012

اكتملت وأُغلقت بتاريخ 2026-10-12. أُنشئت أدوار `mgos_editor` و`mgos_geoserver` بمبدأ أقل صلاحية، ونجح اتصال `MGOS_Editor.sde`، وتحققت الطبقات التسع وأنواعها و`EPSG:32637`. نجحت دورة ArcGIS → MGOS → ArcGIS، ورفضت النسخة القديمة بـ`409`، واستعيدت القيمة الأصلية دون إدخال بيانات اصطناعية. أُعيد ربط مخزن GeoServer بالحساب `mgos_geoserver` للقراءة فقط، ثم اجتاز WMS وWFS التحقق الحي. حُفظ دليل بصري منقح لا يعرض بيانات اعتماد، وتأكد أن كلمة مرور المخزن محفوظة بصيغة محمية. الأدلة في `docs/evidence/012-operational-sync-verification/`.
