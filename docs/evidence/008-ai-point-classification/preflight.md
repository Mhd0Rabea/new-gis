# فحص بيئة المرحلة 008

**التاريخ**: 2026-10-07

- Node.js متوفر ويستخدمه API الحالي.
- PDAL 2.10.0 متوفر من بيئة QGIS التي اعتمدتها المرحلة 007.
- Python 3.14.7 موجود، لكن NumPy وscikit-learn وPyTorch وONNX Runtime وlaspy غير مثبتة.
- القرار: لا تثبيت جديد في الإصدار الأول؛ يستخدم نموذج nearest-centroid صغيرًا داخل Node وPDAL الموجود لاستخراج السمات.
- البيانات: عينتا JSON اصطناعيتان منفصلتان ومتوازنتان، ولا تحتويان مواقع أو بيانات حقيقية.
- بوابة التوسع: لا تُدرس مكتبة ML إضافية إلا إذا أخفق النموذج البسيط في macro-F1 = 0.80 وبعد موافقة صريحة.
