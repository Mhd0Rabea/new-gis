# دليل تحقق المرحلة 011

تاريخ التحقق: 2026-10-11

## ما تم تنفيذه

- مخطط `mgos_staging` ودفعات الاستيراد والمعالم المرحلية ومشكلات التحقق وقرارات المراجعة.
- حقول `source_name` و`source_id` و`row_version` و`updated_by` للطبقات التشغيلية التسع.
- API للرفع والفحص والقرارات والاعتماد والرفض وتقرير CSV.
- معالج استيراد متعدد الخطوات داخل إدارة البيانات.
- فحص تعارض متفائل عند تحديث معلم من MGOS.
- توثيق PostGIS كمصدر الحقيقة المشترك مع ArcGIS Pro وGeoServer وMGOS.

## تحقق ملف المستخدم الحقيقي

استُخدم `gis/MGOS/imports/Military_Bases_Real.geojson` دون إنشاء بيانات بديلة:

- المقروءة: 12؛ الصالحة: 12؛ غير الصالحة: 0.
- التكرارات المحتملة: 12، بالاسم والقرب المكاني من البيانات الموجودة.
- العدد التشغيلي قبل الفحص وبعده: 12؛ لم تحدث كتابة تشغيلية أثناء الرفع والفحص.
- دفعة تحقق ثانية اعتمدت بقرار `skip` للجميع: created=0، updated=0، skipped=12.

## نتائج البناء والاختبارات

- بناء API: ناجح.
- بناء الواجهة: ناجح.
- اختبار عقد الاستيراد يغطي تطبيع حقول ArcGIS والدومينات ورفض الطبقات غير المعتمدة.
- مجموعة الاختبارات القديمة الكاملة تحتوي اختبارات AI تتوقع نموذجًا وملفات تدريب اصطناعية محذوفة عمدًا وفق سياسة المشروع؛ لم تُستعد تلك الملفات.

## النتيجة

أصبح الملف الخارجي يمر بفحص ومراجعة قبل الكتابة، وتبقى PostGIS نقطة الالتقاء الوحيدة بين ArcGIS Pro وMGOS وGeoServer.
