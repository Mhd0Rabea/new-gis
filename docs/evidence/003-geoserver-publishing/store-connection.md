# التحقق من اتصال PostGIS Store

**التاريخ:** 2026-10-03

- Workspace: `mgos`
- Store: `mgos`
- المضيف: `localhost`
- قاعدة البيانات: `mgos`
- المخطط: `public`
- الحالة: مفعّل، والاتصال ناجح.
- الدليل: أتاح GeoServer تسع Feature Types ونشرها، وأعاد WFS أربعة معالم من كل طبقة.

لم تُحفظ كلمة مرور قاعدة البيانات أو بيانات دخول إدارة GeoServer داخل المستودع.
وضع WFS مضبوط على `BASIC` للقراءة فقط، وقد رُفض طلب Transaction فعليًا.
