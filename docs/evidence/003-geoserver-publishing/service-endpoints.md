# نقاط خدمة GeoServer المحلية

- الإدارة: `http://localhost:8080/geoserver/web/`
- WMS Capabilities: `http://localhost:8080/geoserver/mgos/wms?service=WMS&version=1.3.0&request=GetCapabilities`
- WFS Capabilities: `http://localhost:8080/geoserver/mgos/ows?service=WFS&version=2.0.0&request=GetCapabilities`
- WFS GeoJSON مثال: `http://localhost:8080/geoserver/mgos/ows?service=WFS&version=2.0.0&request=GetFeature&typeNames=mgos:Military_Bases&outputFormat=application/json`

هذه عناوين تطوير محلية. لا تُعرض واجهة الإدارة أو بيانات اعتمادها في تطبيق العميل.
