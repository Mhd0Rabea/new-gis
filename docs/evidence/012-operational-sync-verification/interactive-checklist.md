# قائمة التحقق التفاعلية في ArcGIS Pro

- [x] اتصال `.sde` يعمل بدور المحرر المحدود.
- [x] الطبقات التشغيلية التسع متاحة بأسمائها canonical.
- [x] استُخدم سجل `base_id=1` الحقيقي، وحُفظ UUID في `preflight.json`.
- [x] حُفظت قيمة الاسم والملاحظات الأصلية قبل التعديل.
- [x] تعديل ArcGIS عبر `.sde` رفع `row_version` من 1 إلى 2 وظهر في MGOS.
- [x] تحديث MGOS والاستعادة ظهرا عبر اتصال ArcGIS عند `row_version=4`.
- [x] محاولة النسخة القديمة أعادت 409.
- [x] عادت القيمة الأصلية بعد الاختبار ولم تُدخل بيانات اصطناعية.
- [x] مخزن GeoServer يستخدم `mgos_geoserver` بدل حساب المالك.
- [x] WMS وWFS يعملان بعد إعادة الربط، ودور GeoServer للقراءة فقط.
- [x] اللقطات لا تعرض بيانات اعتماد أو معلومات حساسة؛ حُفظت لقطة صفحة المتاجر الآمنة في `geoserver-stores-safe.png`.

اكتملت جميع البنود وأُغلقت المرحلة. لا ينشئ المشروع سجل اختبار بديلًا.
