# سجل تحسينات واجهة الخريطة

**التاريخ**: 2026-10-06

## التحسينات المنفذة

- إصلاح تحديد معالم النقاط والخطوط والمضلعات، بما فيها القطاعات ومسارات الدوريات.
- ربط قائمة طبقة الاستعلام بالطبقات المفعّلة على الخريطة فقط، مع تحويل تلقائي آمن عند إخفاء الطبقة النشطة.
- منع إخفاء آخر طبقة ظاهرة، ومنع انهيار الخريطة عند وصول فلتر غير متوافق.
- جعل مفتاح الخريطة ديناميكيًا وإظهار لون كل طبقة بوضوح.
- ضبط العرض الابتدائي على سوريا، وإضافة انتقال مباشر إلى مدى الطبقة المحددة.
- نقل التحرير المكاني وتفاصيل المعلم إلى نوافذ منبثقة أكثر اتساقًا مع RTL.
- استخدام قوائم منسدلة للحقول المبنية على ArcGIS coded-value domains.
- ضبط ارتفاع الخريطة ليتوافق مع مساحة الشاشة.
- تعريب حقول الواجهة، وإخفاء المعرفات التقنية غير المفيدة، وعرض السجلات المرتبطة بأسماء مفهومة.
- تنسيق الأرقام والتواريخ كقيم مقروءة، مع ساعة بنظام 12 ساعة.
- تحويل أدوات التحرير إلى أزرار أيقونات مدمجة مع أسماء وصول وتلميحات.
- إضافة تسميات خريطة مبسطة مع تقليل التزاحم البصري.
- إضافة بحث مكاني موجّه إلى سوريا عبر OpenStreetMap Nominatim، مع نتائج عربية وانتقال مباشر إلى حدود المكان المحدد.
- إضافة مبدّل خرائط أساس بين الشوارع، والصور الفضائية، والتضاريس مع خطوط الكنتور، وتحديث حقوق المصدر تلقائيًا.
