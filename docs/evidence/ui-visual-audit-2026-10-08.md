# تدقيق بصري تفاعلي للواجهات — 2026-10-08

## معيار التدقيق

- مقياس تشغيلي موحّد: نصوص `11/12/13px`، عناوين حتى `28px`، وعناصر تحكم ثابتة `42px` و`40px` للأيقونات.
- خلفية صلبة لكل زر وحقل تفاعلي، مع مؤشر يد وحالة hover/focus مرئية.
- إزالة النصوص والبيانات التكرارية من رأس الصفحات، وإخفاء المعرّفات التقنية من نافذة تفاصيل المعلم.

## النتائج البصرية الحية

| الصفحة | السيناريو المرئي | النتيجة |
| --- | --- | --- |
| لوحة المعلومات | فتح اختصار «فتح الخريطة» | PASS — انتقل إلى الخريطة الصحيحة. |
| الخريطة | تبديل ستلايت، البحث عن دمشق، اختيار النتيجة | PASS — بقيت خريطة ستلايت مفعلة وتم الانتقال للموقع. |
| الخريطة | فتح سجل من إدارة البيانات ثم تفاصيل المعلم | PASS — فتح مودال التفاصيل، بالعربية ودون معرّفات تقنية. |
| الخريطة | إنشاء معلم ثم النقر على الخريطة وإلغاء العملية | PASS — ظهر مودال الإنشاء بعد اكتمال الرسم ولم يُحفظ سجل عند الإلغاء. |
| إدارة البيانات | تبديل الطبقة والبحث النصي | PASS — تغيرت النتائج إلى 3 سجلات مطابقة. |
| التحليلات | معاينة قراءة البيانات الوصفية | PASS — عرض واضح للبيانات دون عناصر تفاعلية زائفة. |
| التقارير | تبديل طبقة التقرير | PASS — تغير العنوان والجدول إلى الطبقة المحددة؛ زر CSV رئيسي وزر الطباعة ثانوي. |
| مركز المعالجة | اختيار عملية وتشغيل مهمة | PASS — أضيفت المهمة إلى السجل. |
| العرض ثلاثي الأبعاد | إخفاء طبقة مرئية | PASS — تغيرت حالة الطبقة إلى غير مرئية وتحميل 4/4 طبقات ناجح. |

## فحص المظهر العام

جولة مباشرة على المسارات `/` و`/map` و`/data` و`/analytics` و`/reports` و`/processing` و`/scene` أكدت:

- لا يوجد تمرير أفقي على سطح المكتب.
- لا توجد حقول أو عناصر تحكم مرئية بخلفية شفافة.
- لا توجد أزرار فعالة من دون مؤشر تفاعل.

لم يُستخدم `build` أو `lint` كدليل لهذه الجولة؛ جميع النتائج أعلاه من تشغيل الواجهة والتفاعل معها بصريًا.
