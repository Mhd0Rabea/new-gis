# قرار مسار ogr2ogr الاحتياطي

لم يُشغّل `ogr2ogr` لأن مسار ArcGIS Pro/ArcPy الأساسي نجح لجميع Feature Classes والجداول. تثبيت أو إضافة GDAL مستقل في هذه المرحلة يخالف مبدأ الفحص قبل التثبيت ويضيف أداة غير لازمة.

يبقى `ogr2ogr` خيارًا احتياطيًا فقط إذا تعطل ArcPy مستقبلًا، ولا يعد جزءًا من التشغيل الحالي.
